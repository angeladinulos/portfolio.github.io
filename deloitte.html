Deloitte Data Analytics Job Simulation

In this simulation, Daikibo's leadership wanted answers to two questions:

1. Operations: Where and on which machines are the factories losing production time to downtime?
2. People: Are the employees treated fairly across factories and job levels?

Process

Step 1: Import and load the data

I connected Tableau to the telemetry file and selected all schema levels. This flattened the nested JSON into a useful table. I used Automatically Update so Tableau populated the table than opened a worksheet to start building charts. Shown below is the full raw data table.

Step 2: Create calculated field to measure downtime

The raw data only has a text status, so I created a numeric measure labeled as "Unhealthy."

IF [Status] = "unhealthy" THEN 10 ELSE 0 END

Every unhealthy message counts as 10 minutes of downtime and every healthy counts as 0. summing this field gives total downtime in minutes.

Step 3: Build Charts: Downtime per Factory and Downtime per Device Type

I created a new dashboard and placed the factory chart on top and the device-type chart below it. I then set the factory chart to Use as Filter. Clicking a factory updates the device-type chart to show only the factory's machines, so a viewer can directly see on which factory or machine in one click. Furthermore, I also sorted the bars from highest to lowest.

Insights and Conclusion

Downtime Insights
1. Seiko has the most downtime. It has about 480 minutes or about 8 hours of downtime followed closely by Shenzhen at about 420. Together these two factories account for roughly 90% of all downtime while Meiyo and Berlin contribute little.
2. One machine type explain Seiko's problem. When Seiko is selected on the dashboard, the Laser Welder accounts for the entire 480 minutes and every other machine type shows 0.
3. Shenzhen's problem is also concentrated. In the simulation, the Laser Cutter is the dominant source with only small amounts from CNC, Conveyor Belt and Spot Welder.
4. Laser Welders and Laser Cutters are the top two sources of downtime.
