Analyzing Layoffs - Data Cleaning and EDA in MySQL

This MySQL Project analyzes data on layoffs worldwide. The dataset contains columns namely: company, location, industry, total number of people laid off, its percentage, date, current stage of the company (Post-IPO, Series B, Acquired, etc.), country, and amount of funds raised by the company. This is a guided project from Alex The Analyst on his Data Analyst Bootcamp.

This project starts from the process of data cleaning and proceeds to exploratory data analysis using MySQL. The photo below shows a portion of the raw data.

Data Cleaning Process

We start by creating a data “sandbox” or a copy of the raw data. This is where we work with data cleaning and data analysis, where we can work without disrupting the original data. This also helps with recovery in case of mistakes and when we want to trace back on the changes created in the dataset.

Step 1: Remove Duplicates

In the case of this data set, there is no identification number for the companies so a number was assigned for each company over the all columns that should be unique among each entry. This makes it easier to identify the duplicates. The rows with the number greater than 1 indicate that there is a duplicate of that particular column.

To remove duplicates, another staging table was created using “Create Statement” and inserting the data from the first staging table. This table is called and uses the delete function. This is done because the delete function is not applicable for a Common Table Expression (CTE) in MySQL that will update the first staging table.

Step 2: Standardize Data

Detects issues in the format, spelling, spacing etc. in the data and fixes it. All columns were briefly scanned to identify potential issues before changes were implemented. In this section, the following SQL functions are used.

“TRIM” was used to remove unnecessary white spaces in the names.

The function “%” was used to find names, particularly in the industry column, and update names using the “UPDATE” function so they can be consistent throughout the dataset.

Little details such as the extra dots were trimmed from several data items in the data set.

Step 3: Find Null Values and Remove Colums or Rows

Try to populate the blank values by checking other rows or companies that are in the similar category (eg. Airbnb — Travel Industry). For other values that cannot be populated because there is not enough data (eg. total laid off, funds raised, etc.), these columns or data can be removed if justified that it is not needed in your analysis.

Exploratory Data Analysis

For EDA, I started with analyzing maximum amounts for the total number of layoffs and percentage layoffs. Part of the analysis includes grouping by company or industry according to number of layoffs. Additionally, the progression of layoffs per year and the total rolling total per month was analyzed through the substring function in MySQL.
